# Audio Files for 3D Cockpit Asteroids

Place these MP3 files in this directory for full audio experience:

- `laser.mp3` - Short "pew" sound (~0.1s) for laser fire
- `explosion.mp3` - Crunch sound (~0.4s) for asteroid destruction
- `ship_explode.mp3` - Bass thump (~0.5s) for ship destruction
- `thrust.mp3` - Looping rumble (~1-2s) for engine thrust
- `shield_on.mp3` - Electric hum (~0.3s) for shield activation
- `shield_hit.mp3` - Clang sound (~0.2s) for shield impact
- `hyperspace.mp3` - Whoosh sound (~0.8s) for hyperspace jump
- `extra_life.mp3` - Arpeggio jingle (~1s) for bonus life

If files are missing, the game will use synthesized Web Audio API fallbacks.
